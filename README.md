# Orbit

<img src="docs/icon.png" width="72" alt="Orbit">

Конвертер файлов для macOS. Правый клик по файлу → нужный формат → готово.
Работает локально, без загрузки файлов на сервер.

**macOS 14+ · Mac с M1 или новее**

## Установка

1. Скачайте **Orbit-1.5-macOS.zip** из раздела **Releases**.
2. Распакуйте архив, перенесите **Orbit.app** в **Программы** и откройте.
3. В окне Orbit нажмите **«Включить»** и активируйте **Orbit — Конвертировать** в расширениях Finder.

Сборка пока не нотарифицирована Apple. Если macOS блокирует запуск, смотрите [инструкцию Apple](https://support.apple.com/ru-ru/102445).

## Как пользоваться

1. Нажмите правой кнопкой на файл в Finder или на рабочем столе.
2. Выберите **«Конвертировать»**, затем формат в круговом меню.
3. Результат появится в **Загрузки → Orbit** и скопируется в буфер. Нажмите **⌘V**, чтобы вставить файл.

Папка Orbit создаётся автоматически. Исходный файл остаётся на месте.
Можно также перетащить файл в окно приложения.

## Форматы

Изображения: JPG, PNG, HEIC, TIFF и другие. PDF → JPG/PNG по страницам, TXT или DOCX. Документы → PDF, DOCX, RTF, TXT, HTML.
Также есть конвертация аудио, видео, архивов, субтитров и CSV/TSV.

PDF → DOCX извлекает только текст. Распознавания сканов пока нет; сложная вёрстка документов при экспорте в PDF может измениться.

## Сборка из исходников

Нужны Xcode Command Line Tools. Из папки репозитория:

```sh
zsh build.sh
```

Готовое **Orbit.app** появится папкой выше. Перенесите его в **Программы**, затем выполните шаг 3 из установки.
